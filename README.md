# AI Based Face Recognition Attendance System

The AI Based Face Recognition Attendance System is a smart and automated attendance management project that uses Artificial Intelligence (AI) and Computer Vision to mark attendance automatically through face recognition. This system reduces manual effort, saves time, and helps prevent proxy attendance.

The project works by capturing face data of authorized users and creating a dataset. After training the model, the system performs real-time face detection and recognition using a webcam. Whenever a person appears in front of the camera, the system identifies the face and marks attendance automatically.

The attendance records are stored in a CSV/Excel file or a database, including details like Name, Date, and Time.

🔥 Key Features

✅ Real-time Face Detection using Webcam
✅ Automatic Attendance Marking
✅ Accurate and Fast Recognition
✅ Dataset Creation and Model Training
✅ Attendance Stored in CSV/Excel Format
✅ Reduces Manual Work and Proxy Attendance
✅ User-friendly Interface

🛠 Technologies Used
Python
OpenCV
Face Recognition / Machine Learning Algorithms
NumPy, Pandas
CSV / Database (Optional)
🎯 Project Objective

The main objective of this project is to develop a secure, efficient, and reliable attendance system that eliminates the drawbacks of traditional attendance methods such as time consumption and fake attendance.
